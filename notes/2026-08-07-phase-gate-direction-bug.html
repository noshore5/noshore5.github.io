The phase-gate direction bug: reported, "fixed," then reverted

2026-08-07 · EEG seizure prediction, dense-edge GNN

This is a story about a "bug fix" that made things worse, and what it took to figure out why.

The model gates messages between electrode pairs by phase relationship: for a given pair of channels, an edge only "fires" — contributes a message to the graph — if the coherence between them exceeds a threshold and the phase delta exceeds a separate threshold. The original code looked like this: 

gate = (coh > threshold) & (phase > phase_threshold)

This was flagged as looking one-sided: it only catches a phase relationship in one rotational direction. The reasoning was that the sign of the phase angle determines which channel is "source" and which is "destination," so a one-sided gate should be silently dropping half of the real relationships. The fix looked obvious — make it symmetric: 

gate = (coh > threshold) & (phase.abs() > phase_threshold)

Event counts roughly doubled with this change (about 2,470 events/trial one-sided, versus about 4,890 two-sided, across 8 real trials), and an initial accuracy check looked consistent with historical baselines. It seemed like a real bug fix with no downside.

Then it got slower and scored worse

When the model was run at the actual working thresholds (not the looser ones used for the quick sanity check), both training time and accuracy got worse after the change. That was the signal to stop trusting the numbers and re-derive the actual math instead of just re-running it.

Every channel pair is represented as two directed edges — one for i→j, one for j→i. The cross-spectrum between the two channels' wavelet transforms is: 

xwt_real = src_r*dst_r + src_i*dst_i     (symmetric under src/dst swap)
xwt_imag = src_i*dst_r - src_r*dst_i     (antisymmetric under src/dst swap)

Swapping which channel is source and which is destination — going from edge i→j to edge j→i — is exactly a conjugation: xwt(j→i) = conj(xwt(i→j)). Smoothing is applied identically and linearly to both directed copies, so that relationship survives smoothing intact. The consequence: phase(j→i) = -phase(i→j) and coherence(i→j) = coherence(j→i), always, for every pair, at every time/frequency cell.

That means the original one-sided gate was already directionally correct by construction. For a given pair, either i→j fires (phase > +threshold) or j→i fires (phase < -threshold, since phase(j→i) = -phase(i→j)) — the two conditions are mutually exclusive by sign. Exactly one directed edge fires per real phase relationship, and which one fires is what encodes the source/destination direction. The symmetric (.abs()) version breaks this: it's true for both directed edges whenever the pair has a strong phase relationship in either direction, so instead of picking a direction it fires both at once — doubling event volume with duplicate, contradictory-direction edges feeding into the graph.

The gate was reverted to its original one-sided form, with a comment left in the code explaining why it's correct, rather than a bug.

Verifying it two ways

Re-running at the real working thresholds with the reverted gate gave the best single-subject result logged for that setup so far (mean accuracy 0.854, up from 0.836 under the two-sided version at looser thresholds).

More convincingly, the actual numbers were traced on one real trial. For one channel pair, at the time/frequency cell where their coherence peaked: phase(i→j) = +0.241094 rad, phase(j→i) = -0.241094 rad — summing to exactly zero — and coherence(i→j) = coherence(j→i) = 0.999934, matching exactly. The one-sided gate fired correctly on i→j and correctly did not fire on j→i at that cell. Scanning every time/frequency cell for that pair across the whole trial: i→j fired on 1,089 cells, j→i fired on 534 cells, and zero cells fired on both — full mutual exclusivity, confirmed empirically, not just algebraically.

Takeaway

The instinct that triggered this — "this looks one-sided, that's probably a bug" — was reasonable on its face, and the initial "fix" even looked validated by a quick accuracy check. What actually caught it was refusing to accept a regression as noise, and going back to the underlying complex-analysis identity instead of just re-running experiments. The event-count and accuracy numbers alone would never have explained why it broke; the conjugate-symmetry argument did.
