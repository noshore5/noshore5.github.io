A whole-graph spectral model, tuned every way we could think of, closes negative — and points somewhere new

2026-08-27 – 2026-08-30 · hermitian_ssm, Mamba-3, anomaly detection

Over four days, we built a new pipeline from a design doc, ran it for real, found its bug, tuned it from the worst-performing model in the repo to a competitive one, then spent every remaining lever — encoder redesigns, a from-scratch complex-diagonal Mamba-3, a mode-count sweep — trying to close the last gap to the leader. All of it came back negative. That's the useful result: it pins down exactly what's capping this whole family of models, and it isn't representational power.

What hermitian_ssm is

Every other coherence-graph pipeline in the repo collapses the 23-channel EEG montage to a 253-edge coherence graph and pools it down before the temporal model ever sees it. hermitian_ssm instead builds, at every (frequency, timestep), a full 23×23 Hermitian matrix from the cross-spectrum, eigendecomposes it, and feeds the model the top-k eigenpairs directly — a richer, whole-graph-as-one-token representation, with a Mamba-2 temporal head sitting on top and a documented seam for swapping in Mamba-3 later. Built end-to-end from hermitian_ssm.md across one day, including a from-scratch batched Morlet CWT, a deterministic per-recording spectral cache, and a numerical-validation script checking Hermiticity, real eigenvalues, orthogonality, and phase-gauge invariance against synthetic data.

Real CHB-MIT recordings immediately found a bug the synthetic tests couldn't: flatlined electrode segments produce near-zero, near-singular matrices that LAPACK's Hermitian solver refuses to converge on, killing an entire batched call. The fix was a fallback to the general eigensolver for the failing chunk — a different LAPACK routine with no convergence mode, still exact for Hermitian input once re-sorted and phase-gauged.

0.253 → 0.436: the config fix

The first real six-fold run landed at mean AP 0.253 — the weakest full-benchmark pipeline in the repo, versus the temporal_graph_mamba leader's 0.674. Diagnosis found the actual problem: the matrix diagonal was raw per-channel power, and power spikes (one recording's largest diagonal entry hit 3210 against a typical value of 14) were dominating the eigendecomposition, pinning the top eigenmode to a single noisy channel instead of genuine cross-channel coupling.

Config-only, no code changes: mean AP jumped to 0.436, ROC-AUC to 0.947 (edging out the leader's 0.94), and the event-level hit rate went 6/6 raw and 6/6 smoothed — better than the leader's 6/6 raw, 5/6 smoothed. It was no longer disqualified. It was, on several axes, arguably a better model. Just not on the metric this project treats as primary.

Reading the fold pattern is informative: hermitian wins the two folds where the leader is weak (1_15, 1_26) and loses the three where the leader is strong. It's a genuinely different model at this point, not yet a strictly better one.

Every remaining lever, tried and closed

With the low-hanging config fix spent, the next question was whether representation or temporal modeling could close the rest of the gap. Four separate attempts, all negative:

The Mamba-3 piece is worth dwelling on, because it was real, non-trivial engineering, not a quick config flip. Mamba-1/2's state transition is a real exponential decay — each state channel can accumulate or forget, but never rotate. The eigenvector encoder feeds the model a stream of complex numbers whose phase tracks how the coherence structure evolves, and a real-valued recurrence structurally cannot lock onto a rotating phase relationship the way a complex one can. So we built one: a complex-diagonal selective SSM with a state eigenvalue λ = -exp(a) + iω, giving every channel both a decay rate and its own rotational frequency.

The scan itself (ht = Atht-1 + xt) is associative over the complex numbers exactly the way it is over the reals, so the existing parallel-scan algorithm carries over unchanged — the real work was a custom autograd backward pass, since the stock implementation doesn't conjugate correctly for complex inputs. Three faster approaches (a cumulative-product closed form, a chunked log-space method) failed outright — numerical overflow in one case, a non-differentiable kink in another — before landing on a Blelloch parallel scan with a hand-derived conjugate-correct backward, verified against finite differences in double precision on both the scan alone and the full temporal block.

It trained cleanly, gradient-checked correctly, ran at a reasonable ~2× the cost of the real-valued version — and made the held-out result slightly worse. Every fold's internal training curve looked healthy, often healthier than the real-Mamba baseline's. It just didn't transfer to the one held-out seizure per fold any better.

The actual ceiling: data, not architecture

Every one of these four attempts shares the same signature: healthy validation metrics, no improvement (often a regression) on the held-out fold. On chb01 leave-one-seizure-out, each fold's positive class is roughly thirty preictal windows — and every lever tried here adds effective model capacity into that budget. More eigenmodes, richer encoders, a more expressive temporal recurrence: all of it gives the optimizer more ways to fit the training folds' idiosyncrasies instead of the underlying preictal signal.

hermitian_ssm's ceiling on chb01 is about 0.44 mean AP, and every lever that adds representational power comes back flat-to-negative while the internal validation metrics stay fine. That's the signature of a data-budget wall, not a modeling gap. The lever this project doesn't control — more subjects, more seizures — is the one that would actually move it.

A different question: what if we stopped predicting preictal at all?

Every supervised attempt above is capped by the same thirty-window budget for the positive class. The interictal (normal) class has no such shortage. So the last idea of this run flips the task: train only on interictal windows to learn the normal graph-state manifold, then flag departures from it — no preictal labels, no class balancing, no negative subsampling anywhere in the loss.

The model is a next-token predictor over the same eigenvector encoder's token stream: predict each timestep's graph state from the ones before it, and score a window by how badly it violates that prediction. A degraded-config smoke test — two epochs, a shrunk spectral configuration — separated preictal from interictal on held-out seizures at mean ROC-AUC 0.80, mean AP 0.50. That's a smoke test, not a result, but it's the most encouraging early signal the hermitian direction has produced, and it sidesteps the data-budget wall the last four experiments all hit head-on.

Where this leaves things

Encoder variants, temporal-model complexity, and mode count are now closed lines of inquiry for hermitian_ssm — each spent a real session, each came back negative, and together they make a fairly strong case that this architecture family is done being pushed on capacity. The deliverable candidate that survives from the coherence-graph family is temporal_graph_aggregate="post" (mean AP 0.639, a near-tie with the leader, at higher compute cost) — and the interictal-anomaly reframe is the one open thread worth a real six-fold run before this direction is set aside.
