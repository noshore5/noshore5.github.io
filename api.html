The CoherIQs API accepts a window of multi-channel EEG data and returns a seizure-risk score. Scoring is performed with a graph neural network and a selective state-space model built on wavelet coherence features between channels. The underlying real-time wavelet coherence architecture is described in a peer-reviewed IEEE publication (ISPA 2025).

Base URL

https://api.coheriqs.com/v1

Authentication

All requests require a bearer token, issued per user during the beta: 

Authorization: Bearer <token>

Endpoints

POST /v1/score

Submit an EEG window and receive a seizure-risk score.

Request

{
  "sampling_rate_hz": 256,
  "channels": ["Fp1", "Fp2", "F3", "F4", "C3", "C4", "P3", "P4"],
  "samples": [[ ... ], [ ... ]],        // one array per channel, equal length
  "window_seconds": 30
}

Response

{
  "risk": 0.82,                          // 0.0 - 1.0
  "horizon_seconds": 300,                // prediction horizon
  "model_version": "dense-edge-ssm-0.3",
  "window_seconds": 30
}
GET /v1/health

Service status and current model version.

{
  "status": "ok",
  "model_version": "dense-edge-ssm-0.3"
}

Notes

Endpoint shapes and the model version are subject to change during the beta.
