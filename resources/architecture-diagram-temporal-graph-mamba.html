SparseEvidenceGNNCore — forward pass (temporal_graph_mamba pipeline)

The same coherence-graph front end as the dense-edge pipelines, but a genuinely evolving-graph temporal model: event_mode="temporal_graph", temporal_graph_mode="mamba". A persistent Mamba state walks the full downsampled sequence. The temporal_graph_aggregate knob decides whether that Mamba runs per node (after collapsing the 253 edges to 23 channels) or per edge (before). One raw EEG epoch in, one set of class logits out.

Canonical shapes (chb01 seizure-prediction, LOSO): n_channels = 23  →  E = C(23,2) = 253 canonical undirected edges (i<j)  ·  8–40 Hz, nfreqs = 8  ·  256 Hz, 30 s window → T ≈ 7680  ·  dense_edge_time_downsample = 16 → T′ = 480 into the Mamba  ·  temporal_graph_edge_dim = 8, hidden_dim = 8 (= Mamba d_model)  ·  Mamba: d_state 16, expand 2, 1 layer, chunk_size 128  ·  event_aggregation = "mean" (forced), n_hops = 1 (inactive)  ·  no ChannelSignalEncoder lane (cwt_encoder = False)  ·  SPH 300 s / SOP 900 s, batch 32, 20 epochs.

Source: Epilepsy/pipelines/cwt_gnn_classifiers.py (SparseEvidenceGNNCore._temporal_graph_node_states, _DenseEdgeMambaTemporal), wired as --pipeline temporal_graph_mamba in run_pipelines.py. This is a different event_mode from the dense_edge_gru / dense_edge_mamba diagrams: those run the temporal block per edge and pool time away, then aggregate with event_aggregation="concat" and concatenate a ChannelSignalEncoder lane. temporal_graph forces "mean" aggregation, has no channel-encoder lane, and — in "pre" mode — aggregates to nodes before the temporal model so the Mamba integrates a persistent per-node state through the whole sequence. "post" (2026-08-28) is an A/B that moves the aggregation after the Mamba, letting each of the 253 edge coherence trajectories carry its own state. "pre" is the current 6-fold prediction leader on chb01 (mean AP ≈ 0.674, ROC-AUC ≈ 0.94); "post" results pending. Numbers are for the chb01 LOSO config and will differ for other subjects/windows.
