Research

Since august 2025 I've been with a small independent research team (myself and two collaborators) building a machine learning architecture for EEG-based paradigms. The core idea: use complex-valued wavelet coherence between electrode-channel pairs as edge features in a graph neural network, so the model can represent lead/lag phase relationships — i.e. how seizure activity actually propagates across the electrode array — rather than treating each channel independently. A GRU models how that graph evolves over time.

Architecture

The diagram below is a direct read of the code path actually instantiated for training — SparseEvidenceGNNCore's forward pass under the dense_edge_gru config: a dilated Conv1d channel encoder running alongside a coherence/event lane (cross-wavelet transform → cone-of-influence masking and surrogate significance → smoothing/downsampling → a per-edge GRU), which merge and pass through a message network, destination-node aggregation, and a final classifier.

Where things stand

The model classifies active seizure state well. As of 2026-08-17 there's also a first real, non-confounded result on the harder problem — predicting the preictal (pre-seizure) window — on single-subject, leave-one-seizure-out evaluation: mean roc_auc 0.882, hit rate 6/7, with one fold in clinically-interesting territory (auc_pr 0.956, false alarms/hr 1.2) and others weak to near-chance. A label-permutation null control and two leakage-risk checks (fold-boundary exclusion, SPH warn-zone boundary) all came back clean — real roc_auc 0.882 vs. a shuffled-label null at 0.491, chance. Still single-subject, patient-specific evaluation only, and decision threshold is untuned; cross-patient generalization is untested. Suggestive, not yet validated beyond this one subject — see Notes for the full writeup. On standard motor-imagery benchmark tasks, the architecture currently trails EEGNet by a small margin — the working hypothesis is that the model spends representational capacity on time-ordering information that isn't especially useful for motor-imagery classification specifically, even though it matters for seizure propagation. Open thread, not a finished result.
